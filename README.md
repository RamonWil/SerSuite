# SerSuite

SerSuite is a web design and development business I founded to help small businesses build stronger, more professional online presences.

The goal behind SerSuite is simple: create modern, fast, responsive websites that are easy to use and designed around the needs of each client.

[Visit SerSuite](https://sersuite.com)

## About the Project

SerSuite started as a way for me to take what I was learning through software and web development and apply it to real businesses.

Through SerSuite, I've worked directly with small-business clients to design, develop, launch, and maintain production websites.

My work has included:

- Building and launching 5+ production web pages
- Working with 3+ small-business clients
- Designing responsive interfaces for desktop, tablet, and mobile
- Optimizing client websites to achieve 90+ Lighthouse performance scores
- Managing domains, hosting, deployment, and SEO
- Delivering projects through 2–4 week development cycles
